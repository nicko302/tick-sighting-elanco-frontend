# UK Tick Sighting Interactive Map
### Access the demo site here: https://nicko302.github.io/tick-sighting-elanco-webapp/
### Walkthrough video: https://youtu.be/aoYbuUD6Ow8
## Outline
Ticks and tick-borne diseases are a huge concern across the UK. This Minimum Viable Product demonstrates the functionality for a web app to gather live data of tick sightings into a single user-friendly platform to encourage community engagement.

## Features
- Interactive map view of the UK.
- Cities are marked and listed with further information to display all previously tracked sightings, and what they were.
- Implementation of Elanco API for access to mock data.

## Choices
I decided it was important to align the house style of the app with the appearance of existing Elanco websites, namely https://www.elanco.com/us.
Additionally, I made sure that the interactivity is all dynamic and within one webpage so that the user experience doesn't feel too slow, bloated, or overcomplicated. Ensuring that the system looks and feels the best it can is massively important for an app intended to help tackle animal health across the country.
